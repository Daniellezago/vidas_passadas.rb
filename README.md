# 📜 Projeto Vidas Passadas (Past Lives)

Anos 90 de volta diretamente no seu terminal! 🕹️

Este projeto é uma releitura moderna, desenvolvida em **Ruby**, de um clássico e nostálgico programa do MS-DOS que fazia previsões bem-humoradas sobre quem ou o que você foi em uma vida passada, baseado em dados simples como seu nome e data de nascimento.

---

## 🚀 Funcionalidades

* **Cálculo Místico:** Algoritmo baseado em lógica divertida para determinar sua era, ocupação e destino em vidas passadas.
* **Interface CLI Nostálgica:** Interação direta pelo terminal, simulando a experiência do software original.
* **Respostas Divertidas:** Banco de dados com dezenas de combinações de profissões antigas, locais e traços de personalidade.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Ruby
* **Paradigma:** Orientação a Objetos / Scripting de Terminal
